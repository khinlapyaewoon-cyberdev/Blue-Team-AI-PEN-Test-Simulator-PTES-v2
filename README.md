🔍 OVERVIEW
---------------------------------------------------------------------
PTES AI Penetration Testing Simulator is a STRICTLY DEFENSIVE cybersecurity
analysis tool. It simulates the full 12-phase PTES methodology using
reconnaissance (.txt) input and AI reasoning to provide:

• Attack-path awareness (high-level, simulated)
• Defensive gap identification
• SOC playbooks per phase
• MITRE ATT&CK awareness mapping
• OWASP ASVS & OWASP Top 10 assessment
• Executive-level and technical reporting

🚫 NO exploits
🚫 NO payloads
🚫 NO commands
🚫 NO offensive instructions

---------------------------------------------------------------------
▶️ USAGE
---------------------------------------------------------------------
1. Install dependencies:
   pip install streamlit huggingface_hub

2. Configure Hugging Face token in the script:
   HF_TOKEN = "your_hf_token_here"

3. Run the application:
   streamlit run app.py

4. Upload a recon .txt file
5. Adjust LLM temperature
6. Review analysis and download report
